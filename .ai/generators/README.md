# 🎭 Geradores de Dados Sintéticos — GenAI Service

Geradores para criação de massas de teste de conversas, redações de alunos e exercícios.

---

## 🛠️ Geradores Disponíveis
- **`MockEssayGenerator`**: Gera redações sintéticas com erros gramaticais típicos de alunos brasileiros aprendendo inglês.
- **`ConversationSimulator`**: Simula um diálogo de 10 turnos entre aluno e tutor.
